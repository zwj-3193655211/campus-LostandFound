## 8. 物品状态机

```mermaid
stateDiagram-v2
    [*] --> PENDING : 用户发布
    PENDING --> APPROVED : 管理员审核通过
    PENDING --> REJECTED : 管理员审核拒绝
    APPROVED --> FOUND_BACK : LOST 物品 + 完成申请 + 管理员通过
    APPROVED --> RETURNED : FOUND 物品 + 完成申请 + 管理员通过
    APPROVED --> EXPIRED : 定时任务超时
    APPROVED --> CLOSED : 管理员手动关闭
    REJECTED --> [*] : 用户删除
    FOUND_BACK --> [*]
    RETURNED --> [*]
    EXPIRED --> [*]
    CLOSED --> [*]

    note right of PENDING : 默认初始态
    note right of APPROVED : 进入匹配池, 可被用户查看
    note left of FOUND_BACK : 寻物已找到
    note left of RETURNED : 招领已归还
```

## 9. 智能匹配流程图

```mermaid
flowchart TD
    Start([触发匹配<br/>match itemId]) --> Load[加载 item]
    Load --> Type{type?}

    Type -->|LOST| T_LOST[targetType = FOUND]
    Type -->|FOUND| T_FOUND[targetType = LOST]

    T_LOST --> Find[findCandidates<br/>MyBatis selectPage]
    T_FOUND --> Find

    Find --> Cond{有 serialNumber?}
    Cond -->|是| Serial[wrapper.eq serial_number<br/>精确匹配候选]
    Cond -->|否| Cat[wrapper.eq category<br/>且 ±60 天时间窗]

    Serial --> Candidates[返回 300 条候选]
    Cat --> Candidates

    Candidates --> Loop[遍历每个候选]
    Loop --> Score[MatchingEngine.calculateScore]
    Score --> Conf{score > 0?}

    Conf -->|否| Loop
    Conf -->|是| Add[加入 scored 列表]

    Add --> Loop
    Loop -->|遍历完| Sort[按 score 倒序]
    Sort --> TopK[取 topK = min 20, scored.size]

    TopK --> Save[遍历保存]
    Save --> SerialEx{score == 1.00?}
    SerialEx -->|是| TypeSE[matchType = SERIAL_EXACT<br/>status = CONFIRMED<br/>更新物品 matchItemId]
    SerialEx -->|否| IsMatch{score >= 0.65?}
    IsMatch -->|是| TypeWM[matchType = WEIGHTED<br/>status = PENDING]
    IsMatch -->|否| Skip[跳过]

    TypeSE --> Notif
    TypeWM --> Notif
    Skip --> Done([完成])

    Notif[NotificationService.notifyMatchFound<br/>双方推送站内通知 + 邮件]
    Notif --> Done

    style SerialEx fill:#fff7e6
    style Notif fill:#e1f5ff
    style Done fill:#d4f4dd
```

## 11. 匹配确认与拒绝流程

```mermaid
flowchart TD
    A([用户点击确认/拒绝]) --> B{选择?}
    B -->|确认| C[PUT /api/matches/id/confirm]
    B -->|拒绝| D[PUT /api/matches/id/reject?reason=...]

    C --> E[MatchingService.confirmMatch]
    E --> F[selectById 加载 match]
    F --> G{match 存在?}
    G -->|否| H[业务异常 匹配不存在]
    G -->|是| I[加载 lostItem + foundItem]
    I --> J[validateMatchOwnership<br/>用户必须是物品发布者]
    J -->|失败| K[业务异常 无权操作]
    J -->|通过| L[match.status = CONFIRMED]
    L --> M[更新 lostItem.matchItemId / matchScore]
    L --> N[更新 foundItem.matchItemId / matchScore]
    M --> O[MySQL UPDATE]
    N --> O
    O --> P([完成 - 前端可跳详情])

    D --> Q[MatchingService.rejectMatch]
    Q --> R[同样所有权校验]
    R --> S[match.status = REJECTED]
    S --> T[MySQL UPDATE]
    T --> P2([完成])
```

## 22. 匹配算法评分模型

```mermaid
graph TB
    Input[LostItem + FoundItem] --> S1{hasSerialMatch?<br/>trim + toUpperCase + equals}
    S1 -->|是| S1R[score = 1.00<br/>matchType = SERIAL_EXACT]
    S1 -->|否| S2[hasSerialConflict?]

    S2 -->|是| S2P[最终 score *= 0.40 惩罚]
    S2 -->|否| S2N[无惩罚]

    S2P --> S3
    S2N --> S3[加权分计算]

    S3 --> C1[category: 0.25<br/>eq=1.0 / contains=0.8 / else 0]
    S3 --> C2[location: 0.15<br/>id 相等=1.0 / id 不同=0.35 / 文本相似 * 0.8]
    S3 --> C3[brand: 0.10<br/>eq=1.0 / contains=0.8 / 相似 * 0.7]
    S3 --> C4[color: 0.05<br/>normalize 后 eq=1.0 / else 0]
    S3 --> C5[time: 0.10<br/>exp -days/10 衰减]
    S3 --> C6[text: 0.35<br/>title+description+location 文本 Dice 相似度]

    C1 --> Sum[加权和, setScale 2]
    C2 --> Sum
    C3 --> Sum
    C4 --> Sum
    C5 --> Sum
    C6 --> Sum

    Sum --> Threshold{score >= 0.65?}
    Threshold -->|是| Out[保留 score<br/>matchType = WEIGHTED]
    Threshold -->|否| Zero[返回 ZERO, 跳过]

    style S1R fill:#d4f4dd
    style Out fill:#d4f4dd
    style Zero fill:#ffe1e1
```

**权重常量参考**(`MatchingEngine.java`):

| 维度 | 权重 | 满分条件 |
|------|------|----------|
| 文本相似度 (title/desc/location) | 0.35 | Dice 系数 1.0 |
| 类别 | 0.25 | 相等 / 包含 |
| 地点 (locationId) | 0.15 | id 相等 |
| 时间衰减 | 0.10 | 同一天 |
| 品牌 | 0.10 | 相等 / 包含 |
| 颜色 | 0.05 | normalize 后相等 |
| **合计** | **1.00** | - |

匹配阈值 `MATCH_THRESHOLD = 0.65`,高分匹配阈值 `HIGH_CONFIDENCE_MATCH_THRESHOLD = 0.80`。
