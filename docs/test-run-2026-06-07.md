## 4. 关键业务流验证

### 4.1 证件失主自动匹配

DataInitializer 启动时自动触发全局匹配,识别到"丢失校园卡(serialNumber=2024004)"与"拾取校园卡一张(serialNumber=2024004)"**串号精确匹配**,score=1.00,matchType=SERIAL_EXACT,status=CONFIRMED,并创建 MATCH_FOUND 通知推送至用户(34 号 testuser)站内。

### 4.2 JWT 鉴权链路

- `JwtAuthenticationFilter` 每次请求都验证 token 合法性,并从 DB 重新查询 user(实时角色校验)
- 同步设置 Sa-Token 登录态(用于 `@PreAuthorize` Sa-Token 注解)
- BCrypt 密码哈希(种子用户密码 `123456`)
